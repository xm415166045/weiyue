# 评分维度微调（rubric notes）

跨集复用的维度校准。初始 6 维（每维 20 分）：

| 维度 | 含义 | 初版校准 |
| --- | --- | --- |
| 1. 钩子（Hook） | 前 3 秒是否让人停下 | 微阅场景：用「微信读书笔记导出全是乱码/找不到文件」痛点开场优于功能罗列 |
| 2. 信息密度（Info） | 单位时间干货 | 1 支只讲 1 个动作（导出→下载/微阅），不堆功能 |
| 3. 情绪曲线（Emotion） | 是否有起伏/共鸣 | 「终于能像微信一样直接存到下载」的爽点是情绪高点 |
| 4. 可信度（Cred） | 是否像真做过 | 真机录屏 + 文件管理器实锤路径，比 UI 截图更可信 |
| 5. 行动召唤（CTA） | 是否让人想做/想关注 | 结尾给「三步：导出→选格式→去下载/微阅看」+ 关注引导 |
| 6. 传播性（Share） | 是否值得转发 | 「安卓 16 也能静默保存」是踩中分区存储痛点的可转发点 |

## 待校准（复盘后填）
- 维度权重是否要按平台（抖音 vs 小红书 vs 视频号）分化
- 「可爱/亲切感」是否要单列第 7 维，还是并入情绪曲线
